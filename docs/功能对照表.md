## 一、旧界面的功能去向

v1.0.23 是换前端之前的最后一个纯 PySide6 版本。下面是它全部的用户可见入口。

### 顶栏

| v1.0.23 | 现在 | 备注 |
|---|---|---|
| 选择目录 | 菜单 → 引擎 → 选择项目目录 | |
| 启动引擎 | 菜单 → 引擎 → 启动引擎 | 顺带加了残留自动接管 |
| 状态灯 + 状态文字 | 状态栏左侧 | |

### `⋯` 菜单（23 项）

| 复制整段对话 | chat-demo 导出对话（更强：含思考与工具） |

一键全展开实际很少用）。

## 二、chat-demo 的功能状态

### 已可用（纯前端，不依赖云端）

| 功能 | 说明 |
|---|---|
| 聊天 / 流式输出 | |
| 多会话 | 左侧边栏，按时间分组 |
| 编辑用户消息重发 | 改完直接重发 |
| 重新生成回答 | |
| 分支切换 | 同一个问题保留多个回答，可来回切 |
| 对话导入导出 | ZIP 格式 |
| 深浅主题 | 浅色 / 深色 / 跟随系统 |
| 深度思考开关 | |
| Markdown / 表格 / KaTeX | |
| Mermaid 图表 | |
| 代码高亮 + 一键复制 | |
| 文件卡片 / 拖动上传 | 图片走 OCR，非图片在本地模式被拒 |

### 转不了本地（已隐藏）

| 功能 | 为什么 | 现状 |
|---|---|---|
| 语音输入（ASR） | 依赖云端识别接口 | 输入框不渲染语音按钮 |
| 朗读（TTS） | 依赖云端合成接口 | 消息上不渲染朗读按钮；设置里不渲染音色选项 |
| 联网搜索 / 读链接 | 依赖云端检索 | 输入框不渲染搜索开关；agent 的 `web`/`webfetch` 权限设为 deny |
| 位置信息 | 联网搜索用来定位 | 设置里不渲染 |

这些不是「没做完」，是**能力上转不到本地**。留在界面上只会让人以为能用。

## 三、怎么验证

```bash
# 1. 旧版本的函数有没有被删（比 def 名单）
python tools/compare_versions.py v1.0.23 HEAD

# 2. 桥的四个场景（工具调用 / 多轮 / OCR / 中断）
python tools/test_bridge.py

# 3. 文档里的承诺是否被代码兑现
python main.py --claims

# 4. 环境检查
python main.py --selfcheck
```

第 1 条只能证明「没有整个函数被删」，函数内部的逻辑改动查不出来 ——
那部分靠第 2、3 条兜。
