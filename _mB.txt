docs: README 全面对齐 1.2.0 的实现

换前端和加桥之后，README 有一批说法已经不对了。逐条改：

## 明确错误的

1. **「旧的 PySide6 界面保留在菜单里（工具 → 打开旧界面）」**
   这个菜单项已经删了，用户明确要求不要新旧切换。改成说明「旧界面已移除」。

2. **「顶栏菜单」** → 现在是窗口菜单栏，而且多了「引擎」菜单
   （启动引擎 / 停止引擎 / 选择项目目录）。

3. **「OCR 作为工具挂在模型手里」** → 现在桥在收到图片时自动调 OCR，
   模型也还能通过 --ocr 主动调。表格里改成这个说法。

4. **「界面先把 OCR 跑完，结果贴进对话」** → 实际是桥跑 OCR，
   结果拼进请求给模型，**对话里不显示 OCR 原文**。流程图重画。

5. **「每一步都是可折叠的」** → 桥把工具调用转成文本（`✓ bash {...}`），
   不能折叠。改成「每个调用占一行，失败是 ✗，不刷屏」。

6. **操作步骤**：「点选择目录 / 点启动引擎 / 点输入框左边的图片」
   → 前两个在「菜单 → 引擎」，图片按钮是输入框右下角的回形针。

7. **打包命令**：原来贴的是手写 pyinstaller 命令行，
   漏了 `webui` 和 `plugins/webview/*.dll`（漏了后者运行时报
   `No WebView plug-in found!` 且静默退出）。改成用 spec。

8. **依赖**：`PySide6-Essentials` → 还要 `PySide6-Addons`（QtWebView 在里面）。

## 新增的

- **改前端（chat-demo）**：构建命令 + LOCAL_BACKEND 改了哪 7 处
- **协议桥为什么要存在**：两边的协议差异 + 桥做的三件事
- 技术细节表补 `agent_bridge.py` / `ui_web.py` / `webui/`
