v1.0.2: 修 P1 的 7 条 + 加声明断言

## SSE 断流不再静默
   旧实现 EventStream.run() 最后是 except Exception: pass。SSE 一断界面就停止
   刷新，而 send_message 还在阻塞 → 用户看到永久「思考中」，唯一选择是杀进程
   （而杀进程又留下孤儿 OCR 引擎）。
   改：断流通过 on_error 回调报出来；每轮 POST 返回后用消息链对账补渲染。
   流式负责「快」，POST 返回值负责「准」。

## AGENTS.md 路径不再写死
   旧版是仓库里的静态文件，写死 D:\mimo-desktop\tools\ocr.py。装到
   %LOCALAPPDATA%\MiMoLocal 之后模型会去调一个不存在的路径。
   改：启动时按 config.ROOT 生成。
   顺带发现第二层问题 —— 打包后 tools/ocr.py 进了压缩包、磁盘上没有脚本，
   模型根本没法 `python tools/ocr.py`。所以 exe 增加 `--ocr` 子命令，
   windowed 模式没有 stdout，结果写到图片旁边的同名 .md。

## _echoes 从 set 改成计数
   旧实现只增不减：一次对话里发过「继续」「好」，之后模型输出同样文字会被永久吞掉。
   改成 Counter，命中一次减一次。

## _is_our_server 不再认错人
   旧判据只有「/props 有 model_path」，LM Studio 和另一个 llama.cpp 实例都满足，
   于是提示「你上次残留了进程，去任务管理器杀」—— 用户会杀掉无关程序。
   改成比对 model_path 是不是当前模型。

## 权限兜底失败要说话
   旧实现 answer_pending_permissions 返回 0 就什么都不做，请求静默卡到 900 秒。
   改成明确提示「卡在权限上，点停止中断」。

## 命令审计日志
   bash 和 external_directory 都是 allow，模型能跑任意命令。新增
   logs/commands.log 记录每一条命令（时间/状态/命令原文）。
   出事之后这是唯一能还原现场的东西。

## 版本号单一来源
   About 和诊断报告都改用 config.VERSION。

## 声明断言（tools/claims.py）
   把 README 的承诺变成会失败的检查。16 条，全部通过才返回 0。
   比如「README 说会自动降级」→ 断言 CHAT_CTX == 0；
   「README 说不联网」→ 断言 web/webfetch 是 deny。
   不符的要么改代码，要么改 README —— 两者不能同时成立。

## tests/ 可以跑了
   五个脚本的 sys.path 加的是 tests/ 而不是仓库根，直接跑一律 ModuleNotFoundError。
   改成 .parent.parent。

没做的（评估后判断不划算）：
   - KV 显存估算标定（只有边界显卡会误判，工作量 vs 收益不划算）
   - 增量渲染（自用场景消息量不大，改 diff 容易引入新的渲染 bug）
   - 端口自动选择（自用软件冲突概率低）
   - 模型 SHA-256 校验（这个项目不下载模型）
   - CI（跑不了，要 GPU 和 9 GB 模型）
