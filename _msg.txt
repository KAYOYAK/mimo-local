v1.0.15: 会话列表右键菜单（删除/重命名/导出）

用户要求：「对话不能右键，比如删除」。

探测 MiMo Code 的会话 API（实测结果）：
  DELETE /session/{id}            → 返回 true        ✓ 可用
  POST   /session/{id}/delete     → HTTP 503         ✗ 不存在
  PATCH  /session/{id}            → 400，需要 expectedRevision
  带 expectedRevision 再 PATCH    → true             ✓ 可用

实现：
- core/agent.py 加 delete_session() / rename_session()
- 会话列表右键菜单：
    打开
    重命名…        弹出输入框，带 titleRevision
    导出为文本…    把对话导出成 txt/md（剥掉 payload 结构）
    删除这个对话   二次确认后调 DELETE，同时清掉当前会话和本地图片记录
  在空白处右键：新建对话 / 刷新列表

实测：
  删除 3 个会话 → 2 个，delete 返回 True，目标不在列表里
  重命名返回 True，新标题生效
