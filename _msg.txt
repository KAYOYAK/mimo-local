v1.0.17: 切换对话时清 echo 计数 + 实测上下文隔离

用户问：「不同对话要隔开，上下文应该不会串吧」。

两层分开看：

## 模型上下文（答案：不会串）
每个对话在 MiMo Code 里是独立的 session，消息历史完全分开。
实测（起真引擎，两个 session 交叉问）：
  会话 A：请记住暗号「紫色大象」   → 记住了
  会话 B：我刚才让你记的暗号是什么？ → 不知道。我在当前会话的 memory
          和项目 MEMORY.md、历史对话里都搜过了，没有任何关于"暗号"的
          记录。我没有跨会话的记忆。
  会话 A：再问一次                 → 记住了紫色大象（A 还记得）
判定：B 不知道 A 的暗号 → 隔离正常。

## 显示层（发现一个漏洞）
load_session() 和 new_chat() 清了 items / _by_id / _seen / _expanded，
但**没清 _echoes**。_echoes 是「用户发过的原文 → 剩余可吞次数」，
跨对话残留会导致：在 A 里发过「继续」，切到 B 后模型输出同样的
「继续」会被误吞掉。
补 self._echoes.clear()。
