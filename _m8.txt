fix: 补回引擎控制和选目录 —— 删旧界面时漏掉的入口

用户问「原本 MIMO APP 的所有功能都保留了吗」，一盘发现三个入口没了：

  启动引擎 / 停止引擎 / 选择目录

它们原来是 PySide6 顶栏的三个按钮，改成 Web 界面后按钮不显示了，
菜单里也没补，结果打开软件引擎压根不起 —— 发消息必然失败。

改动：
- 菜单加「引擎」组：启动引擎 / 停止引擎 / 选择项目目录…
- _sync_engine_actions()：启停后同步菜单项的 enabled 状态
- _auto_start()：窗口显示 600ms 后自动起引擎（要 20 秒，
  不能卡在构造里），没选过目录时用 Path.home() 兜底
- 状态栏显示「引擎运行中 / 引擎已停止」

至此功能对齐：
  聊天 / 图片OCR / 工具调用 / 多会话    -> chat-demo + 桥
  引擎启停 / 选目录 / 自检 / 断言 /
  诊断报告 / 换模型 / 日志 / 关于       -> 菜单
