chore: Python 3.14.8 -> 3.15.0

用户要求所有工具更新到最新。Python 是本机唯一可自行升级的（Node 和 pnpm
在 C:\Program Files 里，需要管理员权限）。

## 方式

本机 Python 是 uv 管的（`%LOCALAPPDATA%\Python\pythoncore-3.14-64`），
`python` 命令走 `bin\python.exe` 这个 shim，靠同目录的 `.__target__`
文本文件指向真实解释器。改那个文件就等于切换全局 Python。

## 验证（全部通过）

  python --version        -> 3.15.0
  PySide6 6.12.0          -> 装上了，QtWebView 可用
  PyInstaller 6.22.3      -> 装上了
  main.py --selfcheck     -> 45/45
  PyInstaller 打包         -> 成功，76 秒
  exe 启动 + 截图          -> 界面完整（侧边栏/欢迎页/状态栏都正常）

## 一个值得记的现象

exe 从 129.3 MB 缩到 46.1 MB。第一反应是「是不是少打了 Qt」，
但启动截图确认界面完整 —— 是 Python 3.15 + PyInstaller 的能力提升，
不是缺东西。warn 文件里有一条 `missing module named 'collections.abc'`，
这是 3.15 的标准告警，PySide6 照常工作。

## 回滚

logs\rollback-python-3.14.ps1 会把 5 个 .__target__ 改回 3.14.8。
3.15 的 PySide6 装在 Roaming\uv\python\cpython-3.15.0-* 里，不影响 3.14。

## Node / pnpm 没更

C:\Program Files\nodejs 不可写（当前不是管理员）。要更得手动跑官方 installer
或提权，见对话里的说明。
